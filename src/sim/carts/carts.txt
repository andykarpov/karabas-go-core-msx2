# The cartridge tests of run_carts.sh: name, cartridge (sim/build/carts, mkcarts.py), mapper switch
# (0 = auto), frames, the CRC-32 of the last output frame (sim_sys --hash), more sim_sys arguments.

# the same with the OPLL off: "FM NONE" and silence (sim_sys --audio-min / --audio-max).
